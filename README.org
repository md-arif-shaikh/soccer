* About the package
  ~Soccer~ is an [[https://www.gnu.org/software/emacs/][Emacs]] package for getting fixtures, results, standing table, etc for soccer (football) matches inside emacs. Following are some the competitions that are included
  - Premier League (England)
  - La Liga (Spain)
  - Ligue 1 (France)
  - Bundesliga (Germany)
  - Serie A (Italy)
  - Championship (England)
All data are fetched from ~the guardian~ website. The list of competitions is
discovered at run time, so every competition the site covers — including the
cups, the women's competitions and the Scottish leagues — is available, not just
the ones listed above.
* Installation and configuration
** Install
Requires Emacs 29.1 or later.

It's available in [[https://melpa.org/#/][Melpa]]. Look [[https://melpa.org/#/getting-started][here]] for instruction. One can also install it using ~straight~ and ~use-package~
  #+BEGIN_SRC emacs-lisp
    (use-package soccer
      :straight (soccer :type git :host github :repo "md-arif-shaikh/soccer"))
  #+END_SRC
** Set a favourite league
~M-x soccer-dashboard~ opens on ~soccer-favourite-league~. The first call asks
for a competition and offers to remember it, so there is nothing to configure by
hand, but it can also be set outright
  #+BEGIN_SRC emacs-lisp
    (setq soccer-favourite-league "Premier League"
          ;; Optional: follow one club rather than the whole competition.
          soccer-favourite-club "Liverpool")
  #+END_SRC
** Set local time
Nothing to configure. Kick off times are published as absolute instants and are
shown in your own time zone automatically.

Set ~soccer-timezone~ only if you want times shown somewhere *other* than your
system time zone, for instance to follow a league from abroad
  #+BEGIN_SRC emacs-lisp
    (setq soccer-timezone "Europe/London")
  #+END_SRC
~soccer-time-local-time-utc-offset~ has been removed; you can drop it from your
configuration.
** Keybindings
A single binding for the transient menu is usually enough, since every other
command is reachable from it
  #+BEGIN_SRC emacs-lisp
    (use-package soccer
      :straight t
      :bind ("C-c s" . soccer))
  #+END_SRC
** Full working configuration
#+BEGIN_SRC emacs-lisp
    (use-package soccer
      :straight (soccer :type git :host github :repo "md-arif-shaikh/soccer")
      :config
      ;; Optional: show times somewhere other than your system time zone.
      ;; (setq soccer-timezone "Europe/London")
      :bind (("C-c s" . soccer)
             ("C-c s f" . soccer-fixtures-next)
             ("C-c s r" . soccer-results-last)
             ("C-c s t" . soccer-table)))
  #+END_SRC
* The dashboard
~M-x soccer-dashboard~ shows one buffer with the recent results, the upcoming
fixtures and the league table of your favourite competition, one section after
the other. With a prefix argument (~C-u M-x soccer-dashboard~) it asks which
competition to show instead.

Setting ~soccer-favourite-club~, or pressing ~C~ in the dashboard, narrows the
results and the fixtures to that club and points its row out in the table.

Changing competition from inside the dashboard
| Key | Action                                                       |
| ~l~ | Switch competition for this buffer only                      |
| ~L~ | Switch competition and remember it as the favourite          |
| ~c~ | Filter by a club, for this buffer only                       |
| ~C~ | Filter by a club and remember it as the favourite            |
| ~a~ | Drop the club filter                                         |
| ~?~ | The full transient menu, with all of the above               |

How much of each section is shown is configurable
  #+BEGIN_SRC emacs-lisp
    (setq soccer-dashboard-results 5      ; recent results
          soccer-dashboard-fixtures 5     ; upcoming fixtures
          soccer-dashboard-table-rows nil); nil shows the whole table
  #+END_SRC
* The transient menu
~M-x soccer~ opens a transient menu from which every view and command is
reachable: fixtures, results and tables, the per club commands, the org export
and the org-agenda scheduling.
* Inside a soccer buffer
Fixtures, results and tables open in a ~soccer-mode~ buffer. Press ~?~ there for
a transient of everything you can do to it. The plain keys are

| Key   | Action                                             |
| ~?~   | Transient menu                                     |
| ~g~   | Refresh from the source                            |
| ~f~   | Fixtures                                           |
| ~r~   | Results                                            |
| ~t~   | League table                                       |
| ~d~   | Dashboard                                          |
| ~l~   | Switch competition                                 |
| ~L~   | Switch competition and remember it                 |
| ~c~   | Filter by club                                     |
| ~C~   | Filter by club and remember it                     |
| ~a~   | Drop the club filter                               |
| ~F~   | Fixtures of the club at point                      |
| ~R~   | Results of the club at point                       |
| ~s~   | Scorecard of the match at point, with goalscorers  |
| ~w~   | Open the match at point in a browser               |
| ~RET~ | Do the obvious thing with the line at point        |
| ~q~   | Quit                                               |

So from a league table, moving to a row and pressing ~F~ shows that club's
fixtures; from a results list, ~s~ shows who scored.
* Useful interactive functions
  Call these using ~M-x Function~ where ~Function~ is any of the following functions

|--------------------------------------+------------------------------------------------------|
| Functions                            | Actions                                              |
| ~soccer~                               | Transient menu with everything                       |
| ~soccer-dashboard~                     | Results, fixtures and table of the favourite league  |
| ~soccer-set-favourite-league~          | Pick the competition the dashboard opens on          |
| ~soccer-set-favourite-club~            | Pick the club the dashboard follows                  |
| ~soccer-scorecard~                     | Scorecard of a match, with goalscorers               |
| ~soccer-fixtures-next~                 | Fixture for the Next match                           |
| ~soccer-fixtures-next-5~               | Fixtures of the Next 5 matches                       |
| ~soccer-fixtures-full-in-org~          | Full fixtures saved in org file                      |
| ~soccer-fixtures-all-clubs~            | Fixtures for all clubs in a league                   |
| ~soccer-results-last~                  | Result of the last match                             |
| ~soccer-results-last-5~                | Results of the last 5 matches                        |
| ~soccer-results-full-in-org~           | Full list of results in org file                     |
| ~soccer-results-all-clubs~             | Results for all clubs in a league                    |
| ~soccer-table~                         | Full Ranking table                                   |
| ~soccer-table-top-4~                   | Rank table with top 4 teams                          |
| ~soccer-table-bottom-4~                | Rank table with bottom 4 teams                       |
| ~soccer-schedule~                      | Add fixtures in org-agenda                           |
| ~soccer-schedule-league~               | Add fixtures for all clubs in a league in org-agenda |
| ~soccer-schedule-remove-past-fixtures~ | Remove past fixtures from agenda.                    |
|--------------------------------------+------------------------------------------------------|
